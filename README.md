Project Overview
This project presents a Customer Churn Analysis Dashboard built using Power BI to explore customer behavior and identify the factors contributing to churn. The dashboard provides actionable insights into customer demographics, billing information, and service usage patterns to help businesses improve customer retention strategies.
Objectives
Identify the main drivers behind customer churn.
Visualize relationships between churn rate and various customer features.
Analyze how service usage (Tech Support, Online Security, Phone Service, etc.) impacts churn.
Support business decisions with data-driven insights to reduce churn.
Key Insights
Customers without Tech Support or Online Security show higher churn rates.
Senior Citizens and customers with shorter tenure are more likely to churn.
Customers with Dependents or longer tenure tend to stay loyal.
High Monthly Charges are linked with increased churn probability.
